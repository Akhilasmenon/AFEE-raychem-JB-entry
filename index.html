System Features

1. Box Container Enter size and click Generate Box to create the boundary layout.
2. Add Nodes Enter diameter. Click Add or press Enter repeatedly to stack circles.
3. Drag & Move Click and drag nodes to slide them securely inside the box limits.
4. Intersection Check Circles turn Green safely, but turn Red instantly upon overlapping.
5. Fast Delete Double-click directly on an individual node to remove it instantly.
